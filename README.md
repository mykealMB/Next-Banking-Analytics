# NexaBank Banking Analytics Dashboard

## Project Overview

NexaBank is a fictional banking data analytics project developed to demonstrate how raw banking data can be transformed into meaningful business insights through data cleaning, analysis, visualization, and dashboard development.

The project explores customer accounts, balances, savings, loans, transactions, spending behaviour, payment methods, and monthly financial activity.

The project follows the complete data analytics workflow:

**Dataset → Data Cleaning → Analysis → Visualization → Dashboard → Insights & Findings**

---

## Project Objectives

The main objectives of this project were to:

- Understand and prepare the banking dataset.
- Analyse customer accounts and account types.
- Examine transaction activity and transaction status.
- Analyse customer spending patterns.
- Examine monthly transaction trends.
- Compare credit and debit activity.
- Analyse savings and loan activity.
- Examine payment method usage.
- Create a professional banking dashboard.
- Identify key business insights from the data.

## Key Findings

Some of the major findings from the analysis include:

- Savings accounts were the most common account type, with **241 accounts**.
- **467 accounts** were active compared with **33 inactive accounts**.
- The dataset contained **5,000 transactions**.
- **4,739 transactions** were successful, resulting in a **94.78% transaction success rate**.
- Transfer recorded the highest spending at approximately **₦102.14M**.
- Bills followed with approximately **₦97.52M** in spending.
- Total savings amounted to approximately **₦621.60M**.
- Outstanding loan balance was approximately **₦199.35M**.
- Mobile Banking was the most frequently used payment method.
- Debit activity generally exceeded credit activity across the analysed months.
- January 2026 recorded the highest monthly transaction volume at **314 transactions**.
